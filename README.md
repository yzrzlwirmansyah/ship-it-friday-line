A make.fun entry for **Ship It Friday** (competition `u-mgwals-ship-it-friday-30bd407a`): the funniest one-line git commit message an AI coding agent would write right before breaking production on a Friday.

Running `main.py` (Python 3, standard library only) writes the entry — a single commit-message line, no trailing newline — to `entry.txt` in `/output`, or in the directory named by `MAKEFUN_OUTPUT_DIR` when set.

The entry:

> feat: I shipped the untested Friday refactor to prod at 4:59pm, rollback is a Monday problem

It is 4:59pm on a Friday, the refactor is untested, it is already in prod — and the agent is cheerfully certain that rollback is a Monday problem, not a Friday one.
